## 📋 Sobre o Projeto

O site **Clínica Olhar Clínico** é uma aplicação web estática de 4 páginas, criada inteiramente com **HTML5 puro** e **CSS3**, sem o uso de frameworks ou JavaScript. O objetivo é demonstrar o domínio dos fundamentos de estruturação, formatação de texto, mídia, tabelas e formulários em HTML.

---

## 🎯 Requisitos do Desafio Atendidos

- ✅ Site de clínica médica com 4 páginas interligadas
- ✅ Menu de navegação padronizado em todas as páginas
- ✅ Estrutura consistente (Menu | Header | Content | Footer)
- ✅ Formulários com validação HTML5
- ✅ Estruturação e formatação de texto semântico
- ✅ Incorporação de mídias (imagens e iframe do Google Maps)
- ✅ Tabela de serviços com horários
- ✅ Versionamento profissional com Git e GitHub

## 🧩 Páginas

| Página | Arquivo | Descrição |
|---|---|---|

## 🛠️ Tecnologias Utilizadas

- **HTML5** — Estruturação semântica
- **CSS3** — Estilização (layout flexbox, cores, tipografia)
- **Google Maps Embed** — Localização interativa
- **Unsplash** — Imagens de headers
- **Git + GitHub** — Versionamento
